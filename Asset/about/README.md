# ภาพส่วนเกี่ยวกับเรา / About image

วางไฟล์ชื่อ **`about.jpg`** ในโฟลเดอร์นี้
Put a file named **`about.jpg`** in this folder.

| | |
|---|---|
| **ชื่อไฟล์ / Filename** | `about.jpg` |
| **สัดส่วน / Ratio** | 4 : 5 (แนวตั้ง / portrait) |
| **ขนาดแนะนำ / Recommended** | 1200 × 1500 px |
| **ขนาดไฟล์ / File size** | ไม่เกิน 300 KB / under 300 KB |

## เลือกภาพแบบไหนดี / What to pick

เลือกอย่างใดอย่างหนึ่ง / pick one of:

- **ภาพทีมงาน** — ช่างและทีมออกแบบที่หน้างาน สร้างความน่าเชื่อถือได้ดีที่สุด
  **Team photo** — crew and designers on site. This builds the most trust.
- **ภาพขณะทำงาน** — ช่างกำลังทำงานจริง ไม่ใช่ภาพ stock
  **Work-in-progress shot** — real people working, not stock photography.

หลีกเลี่ยงภาพอาคารเปล่า ๆ เพราะซ้ำกับส่วนผลงานด้านบน
Avoid another empty building shot — the Work section above already covers that.

---

**หมายเหตุ / Note:** บนจอมือถือภาพจะเปลี่ยนเป็นสัดส่วนแนวนอน 16:10 โดยอัตโนมัติ
On mobile this switches to a 16:10 landscape crop automatically.

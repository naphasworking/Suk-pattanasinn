# ภาพสำหรับแชร์ / Social share image

วางไฟล์ชื่อ **`og-cover.jpg`** ในโฟลเดอร์นี้
Put a file named **`og-cover.jpg`** in this folder.

| | |
|---|---|
| **ชื่อไฟล์ / Filename** | `og-cover.jpg` |
| **ขนาด / Size** | 1200 × 630 px (ต้องตรงเป๊ะ / exact) |
| **ขนาดไฟล์ / File size** | ไม่เกิน 300 KB / under 300 KB |

## ใช้ทำอะไร / What it does

ภาพนี้จะขึ้นเมื่อมีคนแชร์ลิงก์เว็บไซต์ใน **Facebook, LINE, หรือ Messenger**
ถ้าไม่มีไฟล์นี้ ลิงก์จะขึ้นเป็นกล่องเปล่า ๆ ดูไม่น่ากด

This is the preview card shown when the site is shared on **Facebook, LINE or
Messenger**. Without it, shared links appear as a blank box and get far fewer clicks.

## เนื้อหาในภาพ / What to include

- ภาพผลงานที่ดีที่สุด + โลโก้ + ข้อความสั้น ๆ เช่น "ออกแบบ & รับเหมาก่อสร้าง"
  Best project photo + logo + a short line such as "ออกแบบ & รับเหมาก่อสร้าง"
- ให้ข้อความอยู่กลางภาพ เพราะขอบอาจถูก crop ในบางแอป
  Keep text centred — some apps crop the edges.

**หมายเหตุ / Note:** Facebook จำภาพเดิมไว้ ถ้าเปลี่ยนภาพแล้วยังไม่อัปเดต ให้ล้าง cache ที่
Facebook caches this. After replacing it, clear the cache at
